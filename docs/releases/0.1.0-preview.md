# Lucid 0.1.0 Preview

## Release type

- Channel: `preview`
- Packaging: `unpackaged-self-contained`
- Runtime: `win-x64`
- Signing: `unsigned-ci-artifact`

## Summary

This release establishes the first production-hardening baseline for Lucid:

- deterministic local and CI verification
- unpackaged self-contained release publishing
- source-inclusion policy enforcement
- executor safety and rollback test expansion
- trust, privacy, language-policy, and consent-gate coverage

## Verification gates

- `powershell.exe -ExecutionPolicy Bypass -File scripts/verify-release.ps1`
- `.github/workflows/lucid-build.yml`

## Known limits

- CI artifacts are not Authenticode-signed
- MSIX packaging is deferred
- setup-exe generation requires Inno Setup 6 and is an optional wrapper around the verified zip package
- external-distribution signing is not complete yet
