# ExplainMyPC

ExplainMyPC is a modern Windows intelligence platform designed to help users understand, diagnose, repair, and optimize their systems safely and transparently.

Unlike traditional “PC cleaner” tools, ExplainMyPC focuses on:

* explainable diagnostics
* trustworthy recommendations
* system intelligence
* reversible actions
* performance visibility
* safe maintenance workflows

The application combines:

* modern WinUI 3 interfaces
* modular Rust scanning engines
* telemetry systems
* repair workflows
* rollback protection
* intelligent diagnostics

---

# Vision

Most system utilities overwhelm users with cryptic metrics and aggressive warnings.

ExplainMyPC aims to answer:

> “What is happening on my computer, why is it happening, and what can I safely do about it?”

The platform emphasizes:

* clarity over fear
* diagnostics over gimmicks
* trust over marketing
* intelligence over automation
